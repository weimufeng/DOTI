## 决策门

阶段 2 采用 PDB 直接导入路径。若公开页面可读取，则按页面显示结果导入；若返回 403、要求登录或出现验证码，则停止并记录阻断状态，等待用户提供可访问的数据导出或允许公开页面恢复访问。

每条人格记录均应包含：`hero_id`、游戏版本、MBTI、九型人格、PDB profile URL、抓取日期、许可状态、置信度和更新日期。
